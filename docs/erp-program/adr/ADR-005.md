# ADR-005: Integration architecture

| Field | Value |
|---|---|
| Status | ACCEPTED (2026-10-19, approved by the owner, D-038) |
| Approvers | Chief architect; security architect; technical lead |
| Review by | 2027-04-19 |
| Part | 02 (REQ-ARCH-F02 to F13) |

## Context
The landscape includes banks, GSTN/IRP through a GSP, EPFO and ESIC, biometric devices, weighbridges, telematics, batching-plant controllers, email, WhatsApp and SMS providers, client portals and scheduling tools (Part 02 §4). Government APIs must be called from a backend compliance service only (N16).

## Decision drivers
- Versioned, idempotent APIs (AC-4)
- Credentials never in client code (N12)
- Device and file integrations that fail safely

## Options considered
| Option | Assessment |
|---|---|
| In-application API layer with an ingress reverse proxy (proposed for v1) | No extra product to run; one versioned route space; rate limits and idempotency in the application. |
| Dedicated API gateway product | Adds a component and a licence; justified only when external partners exceed what the ingress can manage. |
| Point-to-point integration per partner | Rejected: no common retry, audit or credential handling. |

## Decision
Start with an in-application versioned API under /api/v<major>/<code>/… behind an ingress reverse proxy. Each external connector runs in an integration service with a credential vault, retries with backoff, circuit breakers and a dead-letter queue. Device data (biometric, weighbridge, batching plant, telematics) enters through an edge ingestion service. Government calls go only through the compliance service, with idempotency and a status check before any retry.

## Consequences
- No connector is active until a real call succeeds (N7).
- Outbound calls use an allow-list of hosts (SSRF control, §10.1).

## Fitness function
Contract tests for every published API (§10.2); outbound host allow-list check in CI once a connector exists.

## Rollback
Connectors are switched off per company by feature flag; the vault entries are revoked.
