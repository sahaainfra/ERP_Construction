## Discovery (REQ-CICD-F01 input)
- The repository had one CI workflow (quality, database, design, audit). Test frameworks present: Vitest only. No E2E tool, no coverage tool, no flag registry, no release record.
- Legacy pipeline (old Prompt 03): not in the repository (CF-001). Nothing is verified as legacy-built here.
- Decision: keep GitHub Actions (the platform the repository uses). Test stack: Vitest with v8 coverage (unit and integration), Playwright 1.55.0 with the local Chromium build (end-to-end), @axe-core/playwright 4.11.0 (accessibility), an in-repo script for performance. k6 was not used: it is a separate binary and the budget is measured on the health endpoint now.
